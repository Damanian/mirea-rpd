# MIREA RPD (MCP-коннектор к rpd.mirea.ru)

Отдельный MCP-сервер и Python-библиотека для работы с сервисом рабочих программ дисциплин РТУ МИРЭА ([rpd.mirea.ru](https://rpd.mirea.ru)).

## Возможности

* 🔍 **Поиск и навигация:**
  * Поиск дисциплин по ключевым словам и учебным планам (РУП).
  * Получение списка кафедр, направлений подготовки и профилей.
  * Фильтрация по учебным годам (`2026-2027` и др.).
* 📖 **Чтение и анализ рабочих программ:**
  * **Титульный лист:** кафедра, составители, рецензенты, компетенции (УК, ОПК, ПК), индикаторы.
  * **Содержание дисциплины:** разделы, темы, часы лекций, практических занятий, лабораторных работ, СРС.
  * **Фонд оценочных средств (ФОС):** формы контроля, критерии оценивания, типовые контрольные задания, вопросы к зачёту/экзамену.
  * **Литература:** списки основной и дополнительной литературы, ссылки на ЭБС.
  * **Полный паспорт РПД:** сборка всех блоков программы в единую структуру.
* 💾 **Выгрузка документов:** скачивание черновиков РПД и сопутствующих файлов на диск.
* 🤖 **MCP-сервер:** поддержка протокола Model Context Protocol (stdio) для подключения к Claude Desktop, Cursor, Antigravity и другим AI-клиентам.


## Установка и запуск

```bash
# 1. Перейдите в папку проекта
cd "C:\Users\Damanian\Documents\ChatGPT\MIREA RPD"

# 2. Создайте виртуальное окружение и установите зависимости
uv venv
uv pip install -e ".[dev]"

# 3. Войдите с учетной записью преподавателя МИРЭА
.venv\Scripts\mirea-rpd login

# 4. Проверьте активность сессии
.venv\Scripts\mirea-rpd status
```

## Подключение как MCP-сервер

Для подключения к клиентам (например, Claude Desktop или Antigravity) добавьте конфигурацию:

```json
{
  "mcpServers": {
    "mirea-rpd": {
      "command": "C:\\Users\\Damanian\\Documents\\ChatGPT\\MIREA RPD\\.venv\\Scripts\\mirea-rpd.exe",
      "args": ["mcp"]
    }
  }
}
```

## Доступные MCP-инструменты

* `rpd_status()` — проверить активность сессии в `rpd.mirea.ru`.
* `rpd_departments(acc_year)` — список кафедр для учебного года.
* `rpd_plan_entities(acc_year, dep_id)` — список направлений подготовки и профилей.
* `rpd_search_disciplines(query, acc_year, dep_id)` — поиск дисциплин в учебных планах.
* `rpd_get_work_programs(acc_year, disc_name, rup_row_id)` — получение списка РПД для строки плана.
* `rpd_get_title(rup_row_id, rp_id)` — титульный лист (составители, компетенции, часы).
* `rpd_get_content(rup_row_id, rp_id)` — разделы, темы занятий, часы лекций/практик/лаб.
* `rpd_get_fos(rup_row_id, rp_id)` — фонд оценочных средств, вопросы к экзамену/зачету.
* `rpd_get_literature(rup_row_id, rp_id)` — рекомендованная литература и ЭБС.
* `rpd_get_full_program(rup_row_id, rp_id)` — сводный паспорт программы.
* `rpd_download_draft(rup_row_id, rp_id, save_path)` — скачивание файла черновика на диск.
