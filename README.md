# MIREA RPD (РПД МИРЭА MCP Connector)

MCP-сервер и Python-библиотека для интеграции с сервисом рабочих программ дисциплин РТУ МИРЭА ([rpd.mirea.ru](https://rpd.mirea.ru)).

## Возможности

* 🔍 **Навигация и поиск:** поиск РПД по дисциплинам, кафедрам, направлениям подготовки, учебным годам и планам (РУП).
* 📖 **Чтение рабочих программ:**
  * Содержание дисциплины (разделы, темы, часы лекций, практик, лабораторных работ, СРС).
  * Фонд оценочных средств (ФОС, контрольные задания, вопросы к зачётам и экзаменам).
  * Списки основной и дополнительной литературы, ссылки на ЭБС.
  * Компетенции (УК, ОПК, ПК) и индикаторы достижения.
* 💾 **Выгрузка документов:** получение файлов черновиков, приложений и готовых рабочих программ.
* 🤖 **MCP-интерфейс:** готовые инструменты для AI-ассистентов (Claude, Cursor, Antigravity).

## Установка

```bash
uv venv
uv pip install -e ".[dev]"
```

## Использование

```bash
# Вход в rpd.mirea.ru
mirea-rpd login

# Запуск MCP-сервера
mirea-rpd mcp
```
